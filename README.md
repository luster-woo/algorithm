## 다룬 알고리즘

| 분류 | 대표 문제 |
|---|---|
| 그래프 탐색 (BFS/DFS) | 토마토, 다리 만들기, 인구 이동, 보물섬, 벽 부수고 이동하기 |
| 최단 경로 (Dijkstra) | 최단경로, 최소비용 구하기, 서강그라운드, 파티, 미확인 도착지 |
| 최소 스패닝 트리 (MST) | 최소 스패닝 트리, 도시 분할 계획, 네트워크 연결, 전력난 |
| 동적 프로그래밍 (DP) | 평범한 배낭, 내리막 길, 파일 합치기 3, Z |
| 완전탐색 / 시뮬레이션 | 연구소, 감시, 치킨 배달, 캐슬 디펜스, 미세먼지 안녕, 스도쿠 |
| 백트래킹 | N-Queen, 계란으로 계란치기, 소문난 칠공주 |
| 위상 정렬 | 선수과목, 문제집 |
| 정렬 / 그리디 | 회의실 배정, ATM |
| 트리 | 트리의 지름 |
| 스택 / 문자열 | 문자열 폭발, 팰린드롬 |
